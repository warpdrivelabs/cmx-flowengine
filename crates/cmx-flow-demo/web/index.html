发起流程

> 20000 触发财务会签；过半同意即通过，剩余任务自动作废
> 50000 走风控+行长审批；否则经理审批后直接完成
经理审批挂两个边界定时器：20 秒发催办（不中断）、30 秒超时升级到总监（中断）。
后台每 5 秒自动检查一次；也可点下方「⏰ 立即检查定时器」手动触发。
部门经理初审按岗位 position(df_mgr) 解析（1 人 → 直派）；
财务组审批按角色 role(df_finance) 解析（3 人 → 落候选池，需认领后办理）。
办理人从 cmx 库 IAM 实时解析。
经理审批后走 callActivity 子流程（逻辑 key fin_review，按发起组织路由）：
总部 → 总部三级复核（财务初审→财务经理复核）；北京分公司 → 沿组织树继承总部； 上海分公司 → 分公司单签。同一份主流程，不同组织跑不同子流程。
详情面板会显示解析到的子流程实例，可直接办理。
